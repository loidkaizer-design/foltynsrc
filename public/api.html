Developer reference

API docs

Resolve a TMDB movie into named HLS servers. The browser generates the provider token after Get sources, then returns the full combined URL ready for an HLS player.

Endpoints

GET/api?id=<tmdb_id>&naming=universe

Returns media information and one or more named servers such as Milkyway or Andromeda. The API returns the raw master playlist; the browser mints the token after Get sources.

{ "success": true, "project": "foltynsrc", "tmdb": "1339713", "servers": [{ "id": 1, "name": "Milkyway", "format": "HLS · master.m3u8", "combined_url": "https://media.example/master.m3u8", "url": "https://media.example/master.m3u8", "status": "pending-client-token" }] }
GET/proxy?url=<combined_url>

Relays the combined HLS URL through foltynsrc, rewriting playlists, segments, keys, and nested variants so playback stays on the relay.

/proxy?url=https%3A%2F%2Fmedia.example%2Fmaster.m3u8%3Ftoken%3D...
GET/health

Returns a lightweight service health response.

Combined URL format

After the browser requests /generate.php on the provider host, it appends the returned token to the master playlist URL and places that full URL inside /proxy?url=. The token stays bound to the viewer's IP. Use the generated Combined URL exactly as returned.

Recommended playback

Use combined_url directly when the player can reach the upstream host. Use /proxy?url=... when browser CORS, token IP binding, or nested HLS URLs would otherwise prevent playback. Keep the URL private because it contains a short-lived access token.
