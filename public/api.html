Developer reference

API docs

Resolve a TMDB movie into named HLS servers, or open a licensed embeddable player. The API generates provider tokens server-side and returns full Combined URLs ready for an HLS player.

Endpoints

GET/api/movie?id=<tmdb_id>

Returns media information and one or more named servers such as Milkyway or Andromeda. /api?id=... remains supported as an alias. Each server includes a server-generated token, raw master playlist, and a full url/combined_url relay URL.

{ "success": true, "project": "foltynsrc", "tmdb": "1339713", "servers": [{ "id": 1, "name": "Milkyway", "format": "HLS · master.m3u8", "combined_url": "https://media.example/master.m3u8", "url": "https://media.example/master.m3u8", "status": "pending-client-token" }] }
GET/api/movie/e/<tmdb_id>

Returns a self-contained licensed video player page for embedding. It resolves the movie, selects a ready HLS server, and loads the server-generated Combined URL through the foltynsrc relay.

<iframe src="https://foltynsrc.vercel.app/api/movie/e/1339713" title="Obsession 2025" allow="autoplay; fullscreen; picture-in-picture" allowfullscreen> </iframe>
GET/proxy?url=<combined_url>

Relays the combined HLS URL through foltynsrc, rewriting playlists, segments, keys, and nested variants so playback stays on the relay.

/proxy?url=https%3A%2F%2Fmedia.example%2Fmaster.m3u8%3Ftoken%3D...
GET/health

Returns a lightweight service health response.

Combined URL format

The API requests /generate.php on each provider host, appends the returned token to the master.m3u8 URL, and places that full URL inside /proxy?url=. The token is generated server-side, may be IP-bound, and is short-lived. Use the returned combined_url exactly as provided.

Recommended playback

Use combined_url directly when the player can reach the upstream host. Use /proxy?url=... when browser CORS, token IP binding, or nested HLS URLs would otherwise prevent playback. Keep the URL private because it contains a short-lived access token.
