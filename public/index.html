Vidsrc.to Replica

Enter a TMDB movie id to get the decrypted HLS master.m3u8 playlist JSON.
Tip: you can also call the API directly:
/api?id=1339713 
{
  "success": true,
  "tmdb": "1339713",
  "title": "Obsession 2025",
  "streams": [
    { "url": "https://.../master.m3u8?token=...", "origin": "..." }
  ]
}

API

Request: GET /api?id={tmdb_id}
Example: /api?id=1339713
Response: JSON object with success, title, imdb, backdrop, and streams[] (each with url, origin, raw). Plus the full raw API response under raw.
